# 소담 (Sodam) — 서비스 기획서

> **혼자여도, 소담하게.**
> 잔소리 대신 다음 끼니를 챙겨요.

2026-10-13 · 수업 과제용 **가상 서비스**

---

## 1. 한 문장 정의

> **소담은 혼자 사는 사회 초년생을 위한 '끼니' 트래커다.**
> **오늘 하루를 15초로 담고, 냉장고에 남은 재료로 다음 끼니를 해결해준다.**

---

## 2. 문제의식 — 혼자 살면, 아무도 안 말린다

### 숫자

| 사실 | 출처 |
|---|---|
| 1인가구 **824만 4천 가구 = 전체 가구의 36.6%** (역대 최대) | 국가데이터처 **2025년 인구주택총조사** (2026년 7월 발표) |
| 1인가구 중 **29세 이하 17.8% + 30대 17.4% ≒ 35%** | 「2025 통계로 보는 1인가구」 (2024년 기준) |
| → **소담이 만날 규모 약 280만 가구** | 위 두 수치로 산출 |

> ⚠️ 발표 시 주의: 1인가구 **최다 연령대는 70세 이상(19.8%)** 이다.
> "36.6%"를 청년 문제로 바로 환원하지 않는다. 1인가구는 연령대가 다양하므로
> **홍보물에서는 "청년층" 같은 연령 한정 표현을 쓰지 않는다.** 숫자는 "역대 최대"와
> "약 280만 가구"로만 말하고, 연령 분해는 기획서·발표 자료 안에서만 근거로 쓴다.

### 서사

혼자 사는 집에는 **마찰이 없다.**

새벽 2시에 라면을 먹어도 아무도 보지 않고, 끼니를 거르면 아무도 묻지 않는다.
사회에 막 나온 20~30대는 생애 처음으로 자기 생활을 혼자 관리한다.
식생활이 무너지는 건 의지가 약해서가 아니라, **말려주는 사람이 없어서**다.

그리고 끼니는 **분량에서 먼저 실패한다.**

```
요리하려고 재료를 산다  →  1인분이 안 나온다  →  반이 남는다
→  냉장고에서 썩는다  →  "사면 버리네"  →  다시 배달  →  반복
```

**이 루프가 자취 식생활의 출발점이다.** 실패 지점은 의지가 아니라 **분량**이다.

### 기존 앱이 실패하는 이유

기록을 요구하고 **그래프를 돌려준다.** 입력은 내가 하는데 출력은 숫자뿐이라
거래가 성립하지 않는다. 그래서 3주 만에 지워진다.

필요한 건 평가하는 앱이 아니라, **다음 끼니를 같이 해결해주는 쪽**이다.

## 3. 타깃 — 페르소나 1명

> **27세, 혼자 사는 사회 초년생** (20대 후반 ~ 30대 초반)
>
> - 좁은 원룸 또는 오피스텔
> - 주방: **인덕션 1구, 냄비 하나**
> - 주 4회 배달 및 외식
> - 요리할 마음은 있지만 시간이 없고, 레시피 찾고 장보는 과정 자체가 번거롭다
> - 건강이 걱정되지만 "관리"라는 말은 부담스럽다
> - 구독료를 낼 수 있는 소득이 있다

이 사람 한 명을 위해 전부 만든다. 대학생·고령 1인가구는 타깃이 아니다.

## 4. 해결 구조 — 닫힌 고리

소담의 세 핵심 기능은 기능 목록이 아니라 **하나의 순환**이다.

```
      ① 끼니 담기 ──────→ ② 끼니 돌아보기 ──────→ ③ 냉장고 구조대
       15초 기록          내 끼니의 생김새      남은 재료로 다음 끼니
                          + 놓친 재료            + 다음엔 덜 사기
            ↑                                          │
            └────────── 먹으면 다시 기록으로 ───────────┘
```

**연결 고리는 "놓친 재료"다.** ②가 "애호박을 3번 놓쳤어요"를 알려주면,
그게 그대로 ③의 입력이 된다 — "지금 남은 애호박부터 쓰는 메뉴 2개."

### ① 끼니 담기 — 기록

**원칙: 하루 총 입력 15초.** 칼로리 입력은 절대 요구하지 않는다.

| 항목 | 입력 방식 | 소요 |
|---|---|---|
| 식사 | 사진 1장 **또는** 아이콘 선택 (집밥·배달·외식·편의점·건너뜀) | 1탭 |
| 냉장고 | **장바구니 결제 시 자동 등록**, 요리하면 차감 | 0탭 |
| 수면 *(부가)* | 잠든/깬 시각 2탭, 또는 "어제 어땠어요?" 3단 (푹·보통·뒤척임) | 1탭 |
| 하루 배분 *(부가)* | 아침/오후/밤 3블록에 아이콘 1개씩 — 일·쉼·사람·잠 | 3탭 |

### ② 끼니 돌아보기 — 진단

판단하지 않고 **보여주기만** 한다.

- 이번 달 끼니 구성: 집밥 3 / 배달 9 / 외식 4 / 편의점 6 / 거른 끼니 4
- 반복 메뉴 TOP 3
- **놓친 재료 TOP 3** ← ③으로 가는 다리
- *(부가)* 늦게 먹은 날과 수면의 관계 등 개인 상관관계 — 무료는 맛보기, 유료는 심층

> 남과 비교하지 않는다. **과거의 나와만 비교한다.**

### ③ 냉장고 구조대 — 개입 ⭐ 주력 메시지

- 지금 남은 재료를 고르면 → 만들 수 있는 메뉴 제안
- 부족한 재료만 장바구니에 담김
- 자주 놓치는 재료는 **다음 장보기에서 분량을 줄여서** 추천
- **커뮤니티 피드**: "대파 반 단 남았는데 뭐 해먹죠?" → 다른 사용자가 레시피 제안

홍보에서 **앞세우는 건 ③**. 정체성을 지키는 건 ①②.
상세페이지는 ①→②→③ 순서로 설명한다.

## 5. 북극성 지표

> ### "이번 달 살린 재료 n개"

소담이 세는 숫자는 이거 하나다. **체중도, 칼로리도 재지 않는다.**

| | 세는 숫자 | 사용자가 느끼는 것 |
|---|---|---|
| 기존 건강 앱 | 체중·칼로리 | 내 몸을 **평가**받는다 → 죄책감 → 삭제 |
| **소담** | **살린 재료** | 내가 **해낸 것**이 쌓인다 → 성취감 → 유지 |

`살림`은 **`살리다`에서 온 말**이다. 버릴 뻔한 재료를 살리는 일이 곧 살림이고,
그게 플랜 이름(`프로 살림꾼`)까지 하나로 이어진다.

---

## 6. 시그니처 — "쉬어가는 날"

배달·편의점·라면으로 때운 날, 죄책감을 주지 않는다.

```
버튼:  오늘은 쉬어가는 날
반응:  쉬어가는 날도 있어요. 다음 끼니만 가볍게 가볼까요?
```

핵심 기능이 아니라 **브랜드 인격**이다. 포스터 소재로 가장 강하다.
`망한`, `실패` 같은 단어는 쓰지 않는다 — 실제로 실패한 것이 없기 때문에.

## 7. 같이 보면 재밌는 것 (부가 기능)

핵심 3개 아래로 정렬되는 작은 기능들. 홍보에서 앞세우지 않는다.

- 수면 기록 / 하루 배분 / 오늘 기분
- 개인 상관관계 리포트 (무료 맛보기 → 유료 심층)
- 익명 비교 — "자취 2년차 평균보다 야식이 1.4배 많아요"
- 건강 상식 카드
- 냉장고 구조대 피드 (사용자 간 공유·업로드)

## 8. 플랜

| 단계 | 이름 | 자아 | 포함 |
|---|---|---|---|
| 무료 | **혼밥러** | 지금의 나 | 끼니 담기 · 끼니 돌아보기 기본 · 룰 기반 자동 피드백 · 구조대 피드 열람 |
| 유료 | **자취장인** (월 5,900원) | 되어가는 나 | 심층 분석 + 대책 · **냉장고 구조대 전체** · 주간 리포트 · 채팅 상담 · **웰컴 키트** |
| 프로 | **프로 살림꾼** (월 9,900원) | 되고 싶은 나 | 위 전부 + **월 1회 영양사 비대면 리뷰 15분** · 소분 세트 혜택 |

- 가격: 혼밥러 무료 / 자취장인 월 5,900원 / 프로 살림꾼 월 9,900원 (가격 예시)
- **트래킹은 전 플랜 무료 개방.** 기본 건강관리를 돈 받고 잠그지 않는다 (브랜드 톤)
- 구독으로 파는 것은 **"얼마나 깊이 봐주는가"**
- 식재료는 **별도 결제** + 구독자 할인 → 구독이 커머스를 끌어온다
- "코칭"이라 부르지 않고 **"살핌"** 이라 부른다

### 웰컴 키트 (자취장인 플랜 실물 굿즈)

- **1인분 계량 스푼**
- 냉장고 소분 라벨 스티커
- 재료 집게
- 소담 그릇 1개

디지털 서비스는 포스터에 찍을 게 없다. 실물이 있으면 ① 촬영 소재가 생기고
② 구독 가치가 손에 잡히고 ③ 인증샷이 돈다. **목업·포스터의 핵심 소재.**

## 9. 경쟁 비교 — "눔 아닌가요?"에 대한 답

| 카테고리 | 하는 일 | 끝나는 지점 |
|---|---|---|
| 기록형 트래커 | 먹은 것을 기록하고 그래프로 보여줌 | **② 에서 끝** |
| 코칭 구독 | 목표를 주고 습관을 교정 | **② 에서 끝** |
| 식재료·밀키트 | 재료를 판다 | **③ 만 있고 ①② 가 없음** |
| **소담** | 기록 → 진단 → **다음 끼니 해결** | **고리를 닫는다** |

> **한 줄 답변: "기록형은 ②에서 끝나고, 커머스는 ③만 있습니다. 소담은 ①②③을 한 고리로 잇습니다.
> 그래서 세는 숫자도 체중이 아니라 '살린 재료'입니다."**

차별점은 "다 합쳤다"가 아니다. **고리를 닫은 것**이다.

## 10. 커머스 확장 — '확장' 단계로 확정

| 단계 | 내용 | 비고 |
|---|---|---|
| 1. 출시 | 부족 재료 리스트 → 기존 장보기 서비스 딥링크 (제휴 수수료) | 직접 물류 없음 |
| **2. 확장 ✅** | **제휴 식료품점과 1인분 소분 세트 자체 상품** (대파 1단 대신 1/3단) | **진짜 차별점** |
| 3. 정착 | 구독자 전용 "이번 주 냉장고 채우기" 정기배송 | 향후 |

**2단계로 확정.** 선택한 메뉴의 재료 세트를 1인분 분량으로 판매하고,
필요 없는 재료는 제외하거나 본인 레시피용 재료를 추가할 수 있다.
"남지 않는 분량"이 상품 자체의 가치다.

## 12. 상세페이지 구성 (다음 단계)

과제 요구 순서: **메인 이미지 → 제품 특징 3가지 → 사용 방법 → 구매 버튼**
전 구간 **반응형** (모바일 우선).

| 섹션 | 내용 |
|---|---|
| 히어로 | 메인 이미지 + "혼자여도, 소담하게." + CTA |
| **선언문 (2번째 화면)** | **큰 타이포로 서비스 정의를 한눈에** — 소담은 혼자 사는 사람의 끼니를 15초로 기록하고, 남은 재료로 다음 끼니를 차립니다 |
| 문제 | 재료 실패 루프 다이어그램 |
| 특징 3 | ① 끼니 담기 ② 끼니 돌아보기 ③ 냉장고 구조대 |
| **사용 방법** | 3 STEP — 탭하기 → 놓친 재료 확인 → 남은 재료로 차리기 |
| 데모 | 냉장고 구조대 · 끼니 담기 누적 바 · "오늘은 쉬어가는 날" 버튼 · 놓친 재료 TOP 3 |
| 플랜 | 혼밥러 / 자취장인 / 프로 살림꾼 |
| 부가 기능 | 작은 목록으로 |
| 푸터 | **면책 문구 3종** |

### 데모 구현 범위 (전부 바닐라 JS)

1. **냉장고 구조대** — 남은 재료 클릭 → 메뉴 2~3개 즉시 표시 + 부족 재료만 표시 (레시피 12개 하드코딩)
2. **끼니 담기** — 아이콘 탭 → 구성 도넛이 실시간으로 채워짐
3. **"오늘은 쉬어가는 날"** — 누르면 위로 멘트 + 다음 끼니 제안 (브랜드 톤 체험)
4. **놓친 재료 TOP 3** — 가상 1주일 데이터 (※ 가상 데이터임을 라벨로 명시)

## 13. 면책 문구 3종 (모든 산출물 하단 고정)

```
본 서비스는 수업 과제로 제작된 가상의 서비스입니다.
실제로 판매되거나 운영되지 않습니다.
```
```
본 페이지의 이미지와 영상은 생성형 AI로 제작되었습니다.
```
```
소담이 제공하는 정보는 일반적인 생활 습관 참고용이며,
질병의 진단·치료·예방을 목적으로 하지 않습니다.
건강에 이상이 느껴지면 의료기관에 상담하세요.
```

### 통계 표기 규칙
- 기관명 + 발표연도 + 기준연도를 **반드시 병기**
- 출처를 댈 수 없는 수치는 **쓰지 않는다**
- 서비스 효과 수치(만족도·개선율 등)는 **전부 금지** — 지어낸 것이 되기 때문
