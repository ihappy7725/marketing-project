## 0. 전체 설계

**길이** 30초 · **비율** 9:16 세로 (SNS 기준) + 16:9 가로 버전 선택
**구성** 5초 클립 5개 + 아웃트로 카드 1개
**톤** 판단하지 않는 룸메이트. 우울하게 시작하지 않는다 — 따뜻한 조명 유지

### 서사 구조

```
문제          →  전환        →  해결         →  감정        →  브랜드
아무도 안 말림   남은 재료      한 번 탭하면    다음 끼니     혼자여도 소담하게
```

### ⚠️ 제작 원칙

- **AI 영상에 한글을 넣지 않는다.** 자막·로고·UI는 전부 CapCut/Canva에서 얹는다
- 클립 1~5는 **기존 이미지의 image-to-video**를 우선한다 (톤 일관성 + 비용)
- 아웃트로(클립 6)는 AI 생성이 아니라 **Canva에서 직접 제작**
- 효능·수치 주장 금지. "건강해진다", "살이 빠진다" 류 표현 없음

No people in frame. Quiet, still, lived-in — melancholy but warm,
never cold or depressing. Very slow push-in. Shallow depth of field.
NO TEXT, NO LABELS, NO LETTERING anywhere.

### 클립 6 — 아웃트로 (4초, **AI 생성 아님**)

```

맨아래  본 서비스는 수업 과제로 제작된 가상의 서비스입니다
        영상 속 이미지는 생성형 AI로 제작되었습니다
```

## 3. 자막 스타일 (CapCut)

브랜드 키트와 동일하게 간다. **가독성이 최우선** — 사진 위에 글씨를 바로 올리지 않는다.

| 항목 | 값 |
|---|---|
| 폰트 | Pretendard Bold (없으면 나눔스퀘어 Bold) |
| 크기 | 세로 영상 기준 화면 높이의 6~7% |
| 색 | 흰색 `#FFFFFF`, 강조어만 연두 `#8FD455` |
| 받침 | 반투명 검정 바 `rgba(0,0,0,0.45)` 또는 하단 그라데이션 |
| 위치 | 하단에서 18% 지점, 전 컷 동일 (튀지 않게) |
| 등장 | 페이드 인 0.3초. 날아오는 효과 금지 |

**강조어 지정** — 15초 · 남은 재료 · 소담하게 (이 셋만 연두)

## 4. 음악 (Suno)

```
Gentle warm acoustic instrumental, soft fingerpicked guitar and light
marimba, slow tempo around 80 bpm, cozy morning kitchen mood,
no vocals, no drums until halfway, gentle build toward the end.
Korean indie folk feeling. 30 seconds.
```

- **볼륨**: 자막 구간에서 -6dB
- **포인트**: 15초(클립 4 시작)에서 살짝 밝아지게 — 문제에서 해결로 넘어가는 지점
- 가사 없음. 보컬이 들어가면 자막과 충돌한다

## 5. CapCut 편집 순서

1. 9:16 프로젝트 생성 (1080×1920)
2. 클립 1~5를 순서대로 배치, 컷 사이 **크로스 디졸브 0.3초**
3. 클립 3 폰 화면에 **대시보드 캡처 합성** (마스크 → 화면 영역에 맞춤)
4. Suno 음악 깔고 30초에 맞춰 페이드 아웃
5. 자막 5개 입력 — 위 스타일 그대로, 받침 깔기
6. 아웃트로 카드(Canva에서 PNG로 내보낸 것) 마지막 4초에 배치
7. **좌하단에 작은 고정 자막**: `AI 생성 이미지 · 가상 서비스` (전 구간 노출)
8. 1080×1920 / 30fps / 고화질 내보내기
